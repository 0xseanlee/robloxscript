關於這些資料

公開顯示 Roblox UserId、個人檔案連結、腳本名稱、次數與執行時間。不辨識裝置；同一人的不同帳號會各算一個帳號，因此帳號數不等於實際人數。

只計入已收到的回報，客戶端可以封鎖或偽造回報；啟動回報不代表後續程式載入或執行成功。舊匿名資料不會還原或公開。開始收集日期以實際部署為準。

不想回報：執行腳本前設定 getgenv().ROBLOX_ANALYTICS_DISABLED = true。
